UNITY SETUP

1. Run Tools > Central Base Defense > Configure enemy and target prefabs.
2. Open the gameplay scene. It must contain the existing PlayerEconomy wallet
   and a base with its configured Base component.
3. Run Tools > Central Base Defense > Connect enemies in open scene. Save.
4. Ground/obstacles need colliders; check Enemy Navigation covers the map.
   Spawn enemies on walkable ground. If a working NavMesh already exists,
   remove Enemy Navigation and use that mesh. Towers must not block navigation.
5. Enter Play Mode. Towers now attack EnemyHealth directly; no additional
   damage bridge is needed. Do not attach the old TowerPreviewTarget demo
   movement/respawn script to production enemies.

INITIAL TOWER VALUES (EDITABLE)

           Range    Damage per enemy    Attack interval
Arrow       9             30                  0.6 s
Cannon     13.5            50                  1.6 s
Magic       9             15                  1.0 s

Arrow/cannon are single-target. Magic chains to at most three distinct enemies
including the first, with up to 3.5 units per jump, all within tower range.
Each magic victim receives equal damage and a 50% movement-speed reduction
for half the attack interval. Repeated slows refresh duration without stacking.
Towers retain their target until invalid or out of range. On acquisition,
nearest wins; distances within 0.05 units tie by highest current HP, then a
stable order.

To tune towers, open the prefab and select its weapon child containing
TowerPreviewWeapon. Edit range, damage, interval or chainRange.
EnemyHealth on each enemy root controls health and Kill Reward (1/2/3/5).
EnemyCombatTarget controls temporary tower health and forwards base damage
to the existing Base component. PlayerEconomy/currency rules are unchanged.
Tests are for standalone validation, not components to attach in the level.
